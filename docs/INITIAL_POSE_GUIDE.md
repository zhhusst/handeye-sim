# 自动种子采集初始位姿指南（当前仿真）

“当前能看到双边”不是充分条件。合格初始位姿还必须在双边可测区域内部留有
局部旋转和平移修正空间。系统现在采用静态检查和实际四方向预检两层验收。

## 操作时看什么

在 RViz 中缓慢调整机械臂，保持指定平板角点的两条相邻边都被激光轮廓截到。
真实现场不要求肉眼看见空气中的激光平面；以Gocator二维轮廓、两个断点和终端数值
为准。一次只做一个小幅调整，再观察数值朝目标范围增大还是减小。第二个终端会实时
给出下列量，全部通过时才允许确认：

| 量 | 当前仿真建议范围 | 调整含义 |
|---|---:|---|
| `x_mid` | \(-30\)～\(30\) mm | 让两个断点在传感器横向尽量居中 |
| `z_mid` | 300～550 mm | 不要离板过远或过近 |
| `safe_margin` | ≥20 mm | 两端点不要贴安全梯形边界 |
| `profile_length` | 50～250 mm | 排除错误线段或异常轮廓 |
| `absolute_endpoint_depth_delta` | ≥15 mm | 两端要有足够深度差，正负方向都允许 |
| `joint_margin` | ≥5% | 任一关节都不要接近限位 |
| `local_ik` | ≥3/4 | 三个有解方向必然覆盖局部X、Y两个轴 |

这些数值是当前 Gazebo 场景、标定板尺寸和传感器安全梯形下的保守充分条件，
不是换硬件后仍不变的通用常数。

## 确认后系统会做什么

系统依次实际尝试法兰局部 `X-、X+、Y-、Y+` 各2°，每次运行无手眼平移伺服，
然后返回参考位姿；若前三个方向已经满足条件，可提前结束。扰动后的要求是：

- `|x_mid| ≤ 3 mm`；
- `safe_margin ≥ 15 mm`；
- 至少3/4方向通过；
- 通过方向必须同时覆盖X轴和Y轴。

预检不通过时不会继续耗时采集到第4或第5帧才失败，而会给出具体失败方向，请重新
调整初始位姿。预检通过后，系统才保存参考帧，并执行默认星形分支及必要的异号、
换序候补分支，直到得到6个安全且旋转多样的种子。

动态预检是最终准入条件，因此静态各项都通过后仍可能被拒绝。这属于保守的提前
失败，而不是标定中途故障：它说明当前位姿附近实际只存在单轴或过窄的安全运动
分支，应换一个初始位姿后重新开始。

## 最实用的调整顺序

1. 先把 `z_mid` 调到约 350～450 mm。
2. 再把 `x_mid` 调到接近 0，至少落入 ±30 mm。
3. 观察 `safe_margin`，优先争取 25 mm 以上。
4. 查看 `|Δz|` 而不是 `Δz` 的正负号；只要 `|z(e2)-z(e1)| ≥ 15 mm` 即可。
   `e1/e2` 仍保持物理边身份，负号仅表示另一种合法的深度顺序。
5. 若 `local_ik` 小于3/4或关节余量过小，把机械臂从关节限位、腕部翻转附近移开。
6. 所有静态量通过后再确认，让系统完成四方向实测预检。
