# 共享形貌生产模式：操作与验证

## 1. 当前默认状态

`calibration.yaml` 已默认设置：

```yaml
solver:
  surface_model: "shared"
  surface_basis_kind: "legendre"
  surface_degree: 3
  shape_scale_m: 0.0005
  shape_regularization: 0.01
```

该模式不是在标定结束后另做一次形貌补偿，而是统一用于：

1. 六种子联合初解；
2. 每次NBV后的全部历史数据滚动重算；
3. 候选共享曲面—激光平面交线预测；
4. 完整状态不确定性下的候选有效性传播；
5. 边际化平板参考系和形貌后的手眼信息增益；
6. 信息饱和停止诊断。

`surface_model: "flat"` 保留为理想平面消融和故障对照。修改该配置后，已经启动的节点
不会热更新；至少需要结束第二终端中的当前标定节点并重新启动标定流程。若同时修改了
仿真噪声，则两个终端都应重启。

## 2. 正常仿真测试

终端1：

```bash
cd /workspace
./scripts/start_simulation.sh --web
```

浏览器打开 `http://localhost:6080/vnc.html?autoconnect=1&resize=scale`，在RViz中设置一个
满足控制台工作包络的初始观察。

终端2：

```bash
cd /workspace
./scripts/start_calibration.sh
```

选择自动六种子或人工六种子，然后按提示启动主动标定。初始化日志应出现类似：

```text
12-DOF-V2 initialized (shared): data_rank=19, data_condition=..., prior_rank=19, prior_condition=..., surface_rms=... mm
```

结果JSON的 `surface` 字段应包含：

- `model: shared`；
- `basis_kind: legendre`；
- `degree: 3`；
- 7个 `coefficients_m`；
- `rms_m` 和 `maximum_abs_m`。

结果JSON的 `diagnostics.data_only` 必须由真实观测计算，负责收敛验收；
`diagnostics.prior_augmented` 另行显示加入形貌正则后的后验秩和条件数。若后者明显优于
前者，只能说明先验稳定了弱形貌方向，不能据此宣称数据本身具有同等可观测性。

若仍显示 `rank=9` 或 `surface.model=flat`，说明运行的是旧进程、旧安装空间或配置被覆盖。

## 3. 0.5 mm固定形貌压力测试

终端1改为：

```bash
cd /workspace
./scripts/start_simulation.sh --web --stress-noise
```

终端2仍运行 `./scripts/start_calibration.sh`。该开关只把平板固定形貌RMS覆盖为0.5 mm，
其余噪声继续来自主配置。每次结果都应保存原始轮廓、实际噪声快照、迭代误差和最终形貌
参数，不能只记录终端最后一行。

## 4. 同一数据的flat/shared消融

为了只比较求解模型，不要让两次自动运动产生不同数据：

1. 先完成一次种子采集并记下 `seeds.json` 路径；
2. 设置 `surface_model: "shared"`，在控制台选择“使用已有种子”；
3. 保存整个运行目录；
4. 设置 `surface_model: "flat"`，再次使用同一个 `seeds.json`；
5. 若要严格比较NBV选姿，应固定候选池和随机种子，并分别报告每轮被选候选，而不能只
   比最后误差。

离线生产回归可直接复现：

```bash
cd /workspace
PYTHONPATH=/workspace/ros2_ws/src/handeye_sim_bridge \
python3 scripts/prototype_shared_shape_calibration.py \
  --trials 10 \
  --poses 12 \
  --candidate-pool 80 \
  --frames-per-pose 18 \
  --condition combined_stress \
  --pose-selection flat_information \
  --output-json data/production_shared_v2_12poses_10trials.json \
  --report docs/生产共享形貌12位姿_10次综合噪声回归.md
```

当前10次结果：共享生产后端收敛率100%，旋转误差P95为0.0075°，平移误差P95为
0.0798 mm，最大平移误差0.0864 mm；平面消融的平移误差P95为0.2987 mm。

2026-08-07完成了多次真实ROS执行链压力测试。运行目录
`data/calibration_runs/20260807_145941`中，动态预检与自动六种子为52.2秒，共享模型在
第7个NBV达到0.0083°/0.0708 mm；旧停止配置在第10个NBV以
0.0022°/0.0372 mm结束。随后三次运行分别不晚于NBV 7、NBV 3和NBV 2首次达到
0.1°/0.1 mm，因此生产默认值改为“至少7个NBV、低于首轮信息增益8%、连续2轮”。

独立复验目录`data/calibration_runs/20260807_fast_stop_validation`在第7个NBV自适应停止，
主动阶段约91.6秒，最终真值误差0.0123°/0.0669 mm。与同一批自动种子阶段的52.2秒
合计约143.8秒。结果文件同时保存实际停止参数，避免后续配置变化后无法追溯。这里的
真值只用于仿真评价，停止决策仍只使用信息增益和可观测性，不读取仿真真值。

2026-08-12将默认形貌由四阶12参数降为三阶7参数后，又用同一困难六种子在0.5 mm压力
场景完成ROS链复验，目录为`data/calibration_runs/20260812_degree3_dual_diag`。六种子
data-only/prior-augmented条件数分别为$5.57\times10^6$和$8.68\times10^3$；系统在
第7个NBV停止，最终误差0.0116°/0.0563 mm，主动阶段约62.8秒。若与已测52.2秒自动
种子阶段相加约115秒。该次主动运行复用了既有种子文件，因此115秒是分阶段实测之和，
不是一次连续计时结果。

## 5. 结果边界

- 上述结果证明共享形貌已经正确进入生产求解器，并在当前仿真固定形貌模型下明显降低
  手眼偏差。
- 它尚不能证明真实平板一定能被三阶Legendre基充分表达，也不能替代真实Gocator实验。
- 共享形貌边际NBV已经接入以保持求解与评分模型一致，但“它比原平面评分更会选位姿”
  仍需单独配对消融，当前不能作为已证实贡献。
- 标定过程中标定件必须保持不动；若形貌或标定件位姿随时间变化，“所有视角共享一个
  形貌”的核心前提不成立。
