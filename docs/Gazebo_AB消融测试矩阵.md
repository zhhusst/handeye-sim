# Gazebo冻结版本A/B消融测试矩阵

## 1. 目的

本矩阵只验证当前仍为`UNPROVEN`的运行时策略。每次实验只改变一个因素，不再向正式
`calibration.yaml`增加实验开关。实验通过命令行参数覆盖或独立实验补丁执行，验证后要么
固化成内部常量，要么删除。

## 2. 冻结条件

每个A/B对必须完全相同：

- 初始关节位姿；
- `simulation_noise.random_seed`；
- 6个物理种子或同一份schema 3种子文件；
- 粗手眼初值15° / 200 mm；
- 候选网格、MoveIt规划参数和最大实验预算；
- Gazebo启动后的控制器稳定等待时间。

每个独立条件至少使用5个可接受初始位姿和3个噪声随机种子，共15次。保存代码提交、
工作区差异哈希、YAML哈希、种子文件、全部候选级联、运动时间和最终结果。

## 3. 统一评价指标

| 指标 | 通过条件 |
|---|---:|
| 完整标定成功率 | 不低于基线5个百分点 |
| 总时间P95 | 小于180 s |
| 旋转误差P95 | 不比基线恶化10%以上 |
| 平移误差P95 | 不比基线恶化10%以上 |
| 无效运动/回滚次数 | 不高于基线 |
| 配置参数与分支数 | 有相同效果时选择更少者 |

一项机制只有在提高成功率、精度或时间至少一项，且不违反其余硬条件时才能保留。

## 4. A/B顺序

### A组：自动种子

| ID | A基线 | B消融 | 主要判据 |
|---|---|---|---|
| S1 | 6个初始包络阈值 | 合并为双边安全、深度、关节余量3组 | 准入率/种子成功率 |
| S2 | 动态四方向预检 | 只做静态局部IK | 失败率/预检耗时 |
| S3 | 平移自动居中 | 只要求ROI安全余量 | 总时间/失边率 |
| S4 | 符号与顺序回退分支 | 仅使用预检安全的两轴方向 | 种子成功率/运动数 |
| S5 | 允许partial seed | 只接受完整目标角 | 初解稳定性/失败率 |
| S6 | 每种子18帧 | 12帧、15帧 | 初解P95/种子时间 |

### B组：NBV评分

| ID | A基线 | B消融 | 主要判据 |
|---|---|---|---|
| N1 | 19个Sigma点有效概率 | 仅名义几何安全余量 | 规划后失边率/评分时间 |
| N2 | 信息增益除以运动代价 | 纯信息增益排序 | 总运动时间/最终误差 |
| N3 | 评分8个候选 | 4、16个候选 | 评分时间/可行率/精度 |
| N4 | 已提交位姿最小间隔 | 仅候选ID去重 | 重复激励率/最终信息 |

### C组：事务安全

| ID | A基线 | B消融 | 主要判据 |
|---|---|---|---|
| T1 | 首次/后续更新幅度门控 | 只保留求解收敛与满秩 | 错误大跳变检出率 |
| T2 | 执行失败后回滚 | 故障注入下强制停止 | 可恢复率/安全状态 |

T组不通过“关闭安全保护直接运行”的方式测试。使用越界轮廓、异常端点和规划失败故障
注入，证明保护能否检出并恢复。

### D组：停止

| ID | 设置 | 当前证据 |
|---|---|---|
| P3 | 首轮相对增益3%，连续3轮 | 12 NBV，主动阶段约135 s |
| P5 | 首轮相对增益5%，连续3轮 | 8 NBV，主动阶段约89 s |
| P7 | 首轮相对增益7%，连续3轮 | 与当前轨迹P5停止位置相同，待独立运行 |

当前正式基线选择P5。协方差和留出分数只保存为诊断，不再作为A/B中的停止分支。

## 5. 当前冻结基线

- 单轮MAD-TLS断点拟合；
- 6个物理种子，每种子18帧；
- 12-DOF-V2权重`1 / 0.25 / 0.25`；
- 8个候选进入完整信息评分；
- 15帧NBV批次，其中3帧仅作诊断；
- 至少3个NBV；
- 相对信息增益低于首轮5%连续3轮停止；
- 26个物理位姿紧急保护；
- 最终保留最后一次事务验收通过的滚动解。
