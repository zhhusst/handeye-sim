## 第三方代码

Gocator GoSdk/kApi的最小本地运行集位于`third_party/gocator_sdk`，约21 MB。
它不属于本项目Apache-2.0代码。公开或再分发前必须核对LMI Technologies许可；
也可以删除该目录并在构建时通过`GOCATOR_SDK_ROOT`指向合法的系统安装。

FANUC EIP Python实现依赖`pycomm3>=1.2,<2`，开发容器已在Dockerfile中声明。

4. 真机observe-only完成FANUC、Gocator、断点和同步位姿验证；
5. 单独归档控制器TP程序、UTOOL/UFRAME和寄存器映射；
6. 源码依赖扫描不出现`welding_robopath`或`/home/ws/src`。

达到上述条件前不要删除旧目录。
