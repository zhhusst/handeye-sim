## 重要边界

种子采集节点只负责 Phase 0b，不使用 URDF 手眼真值。候选评分模块始终对一个固定
的法兰命令传播状态不确定性。NBV 候选加入信息矩阵时，会对增广数据重新执行角点变量投影，
而不是把一个孤立的候选 Jacobian 简单相加。

初始位姿验收不再等同于“当前一帧双边可见”。静态层以实际轮廓、关节限位和
局部IK限定一个保守充分包络；动态层实际执行局部 ±X/±Y 各2°并检查平移伺服后的
安全余量。离线鲁棒性回放覆盖60个独立几何采样和3个历史位姿：静态与动态两层
共同通过39组，六种子采集成功39组；两组历史失败位姿均在正式采集前被拒绝。
该统计是当前仿真模型内结果，不外推为实物成功率。

2026-07-26 的端到端仿真记录：6帧自动种子后初始化误差为0.2644°/0.9334 mm；
执行1帧MoveIt规划的NBV并事务提交后为0.0505°/0.4171 mm。该数值只代表当前随机噪声
仿真运行，不是实物精度声明。

同日对候选级联修正后，使用故障复现数据连续执行3帧NBV：首帧、第二帧、第三帧的
关节空间运动距离依次为0.937、0.609、0.542 rad，最大单轴变化依次为40.4°、24.6°、
17.5°；三帧均通过目标状态自碰撞和MoveIt连续路径检查，最终仿真误差为
0.0401°/0.3902 mm。

对真实帧域判据和回退策略修正后，同一故障数据连续完成5帧NBV。规划候选要求位于
内层安全域并保留至少10 mm名义ROI余量；执行后的真实帧按文档要求使用外层硬有效域。
若真实帧越出硬有效域，则丢弃该帧、拉黑候选、回退并验证新鲜双边数据后自动重选，
而不再把一次可恢复的候选失败标记为整次标定失败。

同日完成仿真运行时间与通信稳定性修正：场景轮廓以10 Hz有界频率生成，轮廓图以
3 Hz显示，ROS 2进程统一使用Fast DDS UDP传输，避免反复重启后的共享内存端口锁。
种子阶段采用5°分支目标、2°旋转小步、1 mm安全试探、0.55秒轨迹和0.2秒稳定
等待；局部平移灵敏度可在同一参考邻域复用，失配时会回退并重新试探。NBV每轮评分
16个已通过前置过滤的候选。最终不同初始位姿计时中，动态预检和6个种子约135秒，
5个NBV约33秒，总自动阶段约168秒；最终仿真误差为0.1853°/0.8947 mm，约化
Jacobian秩为9、条件数为20.97。该计时不含人工设置初始位姿。

同日进一步检查亚毫米精度时发现：旧实现把一个NBV的5帧轮廓拼成一个测量，却只给
这个合并测量绑定最后一帧法兰位姿；控制器的微小收敛运动因此成为不符合刚体模型的
系统误差，协方差也会明显过于乐观。现已改为以发布帧时间戳严格配对轮廓、物理断点
和编码器法兰位姿，并将5个独立同步观测作为一个物理NBV事务提交。复用同一组六种子
的10-NBV名义噪声运行中，初始化为0.0340°/0.2997 mm，NBV 1为
0.0065°/0.0362 mm，NBV 3为0.0033°/0.0034 mm，NBV 10为
0.0004°/0.0031 mm。真值只用于仿真结果评价，未参与求解、候选评分或停止。

2026-07-27 修正了初始包络对端点深度顺序的错误限制。固定 \(e_1/e_2\) 是为了
保持物理边身份，不代表必须 \(z(e2)>z(e1)\)；准入条件已改成
\(|z(e2)-z(e1)|\ge15\) mm。用户复现位姿
`x_mid=8.958 mm, z_mid=514.576 mm, Δz=-96.903 mm` 修改后静态验收通过，
动态预检3/4方向通过并采满6个种子。随后5个NBV均完成，NBV 1误差为
0.0065°/0.0417 mm，最终为0.0019°/0.0048 mm。40个随机几何位姿加3个历史
位姿的离线回放中，动态完全合格的24例有23例采满种子；负深度顺序的动态合格
7例全部采满。以上仍仅为当前仿真模型结果。
